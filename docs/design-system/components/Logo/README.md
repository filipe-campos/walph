# Logo

The Walph brand as a component: full logo (symbol + "walph") or the symbol alone, drawn as inline SVG from the same geometry as the files in **Logos**.

**The consumer provides:** `variant` (`'full'` default · `'symbol'`), `tone` (`'color'` default, gradient `accent-3` → `accent` over `accent` → `accent-2` · `'mono'` in `ink` · `'dark'` in `bg-000`, for light backgrounds), `size` (height in px; default 28) and `title` (default "Walph", becomes the accessible name).

- The symbol is cropped to the drawing box (no margin); the clear space is up to the consumer: half the symbol height.
- Minimums: 20px height for the full logo, 16px for the symbol.
- `Welcome` uses `Logo` at 52px. In the title bar and in tabs, use the symbol at 16px.
- Do not animate the brand. The only continuous motion in the interface remains the AI's.
